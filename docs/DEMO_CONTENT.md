## The "before" state — intentionally competent but generic

- Blue/purple gradient background
- Oversized all-caps headline
- Glossy, high-contrast CTA
- Small date/place label
- Conventional event-landing-page feel
- A little too much generic AI/SaaS polish

## The "after" proposal — a community event program

- More negative space
- Clearer hierarchy for **date + place**
- Quieter, more editorial type treatment
- Less aggressive CTA
- Warm paper / wayfinding details, subtle grid, poster-like structure
- **No** beach / ocean / palm-tree cliché
- **No** invented event details
